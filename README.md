# Cofetăria Prăjituri Dulci

Site de prezentare static, realizat cu HTML, CSS și JavaScript vanilla.

## Structura proiectului

```text
.
├── index.html
├── pages/
│   ├── despre-noi.html
│   ├── produse.html
│   └── contact.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   ├── images/
│   │   ├── hero.jpg        
│   │   ├── tort.jpg
│   │   ├── prajituri.jpg
│   │   └── deserturi.jpg
│   ├── icons/
│   └── fonts/
└── README.md
```

## Pornire locală

Deschide `index.html` direct în browser sau folosește extensia VS Code **Live Server**.

Imaginile din `assets/images/` sunt opționale: interfața are culori de rezervă până când sunt adăugate imaginile reale.
